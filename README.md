# Azure AI Fundamentals Projects

A collection of hands-on projects from my **Azure AI Fundamentals** learning journey. Each repository explores a different use case and documents the tools, approach, and lessons learned.

> These are educational portfolio projects. They are intended to demonstrate applied learning; they are not presented as production services.

## Projects

### 1. AI History and Governance Agent
An Azure AI agent that answers questions about the history of artificial intelligence and AI governance, including key milestones, institutions, policy developments, and ethics.

[View the AI Governance History Agent repository](https://github.com/Licyia/ai-governance-history-agent)

### 2. Business Analysis Agent
An Azure AI agent focused on business analysis concepts and the Business Analysis Core Concept Model (BACCM). This project connects my Azure AI learning with the business analysis field I am transitioning into.

[View the Azure Business Analysis Agent repository](https://github.com/Licyia/azure-business-analysis-agent)

### 3. Document OCR and Content Extraction
A Python client for Azure AI Content Understanding that analyzes a document URL and returns extracted text and structured results. The repository includes its architecture diagram, Foundry screenshots, setup guidance, and roadmap.

[View the Azure Content Understanding OCR repository](https://github.com/Licyia/azure-content-understanding-ocr)

## Learning goals

- Practice connecting Python clients to Microsoft Foundry and Azure AI services
- Explore agent instructions, model configuration, and document analysis workflows
- Apply Microsoft Entra ID authentication and environment-based configuration
- Document limitations, responsible handling of documents, and possible next steps

## About this collection

The projects are maintained in their own repositories so each can have its own source code, setup instructions, screenshots, and development history. This page serves as a single index for the collection.
